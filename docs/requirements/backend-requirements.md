# 股票研究辅助系统：后端需求

版本：0.1｜日期：2026-10-05｜状态：需求基线，尚未开发

配套文件：[前端需求](frontend-requirements.md)、[数据库需求](database-requirements.md)。

## 1. 范围与运行环境

Python＋FastAPI；部署于Mac M3、16GB内存、512GB存储。个人使用、首期单只A股、预留多股票。手动导入CSV/Excel，预留行情和联网AI适配器。无下单、账户连接、自动交易和固定止损功能。

每月一次训练为使用约定，第一版手动启动；用户收盘后手动预测。初期采用模块化后端与独立训练工作进程，无需先拆分微服务。

## 2. 模块和资源管理

- 行情与导入：解析、预检、入库、聚合、数据版本。
- 特征与实验：因果特征、训练窗口、滚动验证、参数优化。
- 模型管理：模型文件、指标、诊断、按周期选模与版本。
- 预测：次日OHLC、中长期分位数、历史追踪。
- 策略研究：参考价格区间及明确规则的验证。
- AI解释：检索、来源归档、基于模型结果的说明。
- 任务管理：排队、状态、取消、失败恢复。

训练放在独立工作进程，默认同时只执行一个重型任务。预测与训练的并发规则按内存实测确定；限制输入大小、试验次数、运行时长、线程和深度模型规模。使用有界搜索和提前停止，不承诺优化必然得到达标模型。

任务状态：queued、running、succeeded、failed、cancelled。取消请求记录在cancel_requested字段，在可中断节点停止；不得将部分产物登记为完成模型。重启后识别中断任务并标记失败或按明确恢复机制重试。

## 3. 数据接入与清洗

日线必需：股票标识、交易日期、open、high、low、close、volume。amount可选。分钟线使用带市场时区含义的时间字段。metadata必须说明价格口径、周期、成交量单位及数据来源。

校验正价格、非负成交量、OHLC关系、重复时间、空值、排序与交易日期。停牌、节假日和真实缺失分别处理，不将前值填充记录视为实际交易行情。

上传先预检再确认提交；重复数据默认跳过，冲突不静默覆盖。替换策略生成新版本并保留旧版引用。文件解析支持字段映射，Excel不执行宏。

以统一DataProvider接口连接未来数据源，区分历史日线、分钟线、股票信息、交易日历与复权因子能力。未配置时明确返回不可用。

保留原始价格与复权因子，训练、展示和参考价格的口径必须一致或明确转换。因子及价格修订记录时间，避免当前复权数据未经检查进入历史回测造成信息泄漏。

分钟聚合尊重交易时段，不能跨休市段；1小时等非整除周期的对齐、末尾不足长度处理规则必须版本化。月线聚合保留未完成月份标识。

## 4. 预测目标

次日指下一交易日，输入仅到最近完整交易日。学习开盘相对前收变化、收盘变化及上下影线等受约束目标，输出合法OHLC以及各字段区间；实际建模方式可调整但须满足价格关系。

一个月、三个月以日级路径、各预测步长分位数和期末收盘价区间为主要输出。产品终点按市场日历计算；约20/60交易日可作为实验标准目标，必须与实际预测期限区别记录。

期末收盘区间、逐日区间、全路径覆盖区间、期间极值是不同目标。仅输出已建模且通过验证的目标，不能从边际区间直接宣称整个期间覆盖。

最长7个月持有分析采用月度复核；计划剩余期限超过验证范围时返回unsupported_horizon或范围说明。7个月预测模型为待确认扩展，不自动包含于首版。

## 5. 模型池与训练

### 5.1 候选模型

必须保留简单价格/收益率基准。统计模型：ARMA（可由d=0的ARIMA实现）、ARIMA、SARIMA/SARIMAX。季节项需要验证，不强行设定股票季节性。

GARCH负责条件波动，可与均值模型组合，不能当作单独的方向预测模型。机器学习优先LightGBM分位数；进阶比较小型N-HiTS，PatchTST为可选实验。频域/小波分析为因果诊断或特征模块。

第一版以监督学习与时间序列分析为主，不实施强化学习交易代理。数据不足时跳过不适用模型并记录原因。

### 5.2 验证与参数优化

采用时间顺序的滚动训练与验证，可比较扩展窗口、固定长度窗口。所有标准化、特征选择、缺失处理、频域变换及参数搜索仅在当次训练窗口拟合。

多步标签不能跨入验证期；设置与目标期限一致的隔离规则。校准数据在时序上独立于模型拟合数据，最终测试数据不参与搜索或校准。

参数搜索限制ARIMA阶数、季节组合、训练窗口、树深/叶数/正则化、网络规模/学习率等。优化工具待实现阶段确定。保存全部试验和失败原因；长时间无改善提前停止。

最终测试期独立验收；失败后不可利用同一测试结果持续调参并继续称其为未见数据。后续实验须明确重新划分评估数据或等待新增数据。

每月重训产生新模型版本。预测时可用新行情更新输入，统计模型可按已验证方式更新状态；若发生状态更新，记录对应状态快照，区分于参数重训。

## 6. 评估、校准与选模

点预测：MAE、RMSE、方向表现、相对基准改善；OHLC分字段报告。区间：覆盖率、宽度、分位数损失；按预测步长、滚动窗口统计，记录样本量。

诊断：残差时序/分布、ACF/PACF、适用的自相关与异方差检验。多步误差区分步长及重叠标签的相关性，不将检验结果等同盈利能力。

可尝试适合时序的自适应保形校准；声明目标覆盖率、实际覆盖率和方法假设，不保证未来覆盖。分位数交叉必须处理，并重新评估处理后的区间。

按次日、一个月、三个月分别选择最多三个模型。通过标准包括相对基准表现、跨窗口稳定性、区间质量和数据充分性；具体数值阈值待确定，须在运行前冻结为版本化策略。不能仅因训练误差低就入选。

无达标模型时仍保存研究报告，正式预测或参考买卖区间返回不可用原因。模型排名、最终验收和部署状态分开管理。

## 7. 参考区间与持有分析

参考买入/卖出区间需有明确、事先定义的规则与历史验证。策略回测使用当时已知数据，不能选择事后最高价成交；费用、滑点、成交可行性及适用的A股交易约束按有效日期配置并在实施时核实。

优先比较持有基准、目标区间分批退出、达到目标后回落退出等规则；评估回撤、收益、持有时长、频率和样本量。规则与参数待确认，未验证时只输出模型区间。

输入可选参考价格、观察起始日期；分别计算到目标下沿、中位、上沿的空间。10%为用户关注的观察阈值，不是自动交易条件；无固定止损，不对接订单。

## 8. 联网AI

通过可替换适配器预留模型服务和联网检索；密钥仅保存在本机配置或安全存储，不返回浏览器，不进入数据库正文和日志。

AI读取已完成的模型数值、诊断摘要及带来源时间的信息，输出事件解释和情景，不自行更改模型预测数字。解释应结构化包含来源、事实/推断区分、发布时间、检索时间、模型分歧及信息不足。

AI故障不使已成功的模型预测失败：分别记录数值预测状态与AI状态，允许重试解释。首版不将当前新闻混入历史回测；将新闻作为模型特征需要点时历史语料与独立验证。

## 9. API草案

统一前缀/api/v1；以下为待开发接口契约，尚不存在实际服务。

| 方法与路径 | 用途 |
|---|---|
| GET /stocks | 股票列表与数据可用性 |
| POST /stocks | 注册股票标识，首期可只启用一只 |
| POST /imports/preview | 文件预检、映射和冲突预览 |
| POST /imports/{id}/commit | 按确认策略提交导入 |
| GET /imports/{id} | 导入状态与错误报告 |
| GET /market/bars | 股票、周期、时间范围与价格口径查询 |
| POST /training-runs | 提交训练任务，返回202与job_id |
| GET /training-runs/{id} | 配置、试验、评估与结果 |
| GET /models | 按股票、周期查询模型及入选状态 |
| GET /models/{id}/diagnostics | 模型诊断与图表数据 |
| POST /predictions | 提交预测任务，返回202与job_id |
| GET /predictions | 查询历史预测 |
| GET /predictions/{id} | 数值、区间、参考分析与AI解释 |
| POST /predictions/{id}/ai-analysis | 重试或追加AI解释版本 |
| GET /jobs/{id} | 异步任务状态与阶段 |
| POST /jobs/{id}/cancel | 请求取消 |
| GET /integrations | 接口配置状态，不返回密钥 |

预测请求至少含stock_id、data_snapshot_id、horizon、model_ids和with_ai；服务校验模型股票、周期、价格口径及状态是否匹配。响应包含data_cutoff、generated_at、model_version、区间定义和validation_horizon。

任务提交支持幂等键；查询使用分页或有界时间范围。错误统一code、message、details、request_id；约定400/422输入问题、404资源不存在、409状态/数据冲突、503依赖不可用，具体接口失败语义实施时固化。

## 10. 本地运行与验收

默认仅监听本机，限制允许的前端来源；文件保存到专用目录，验证类型、大小与路径。依赖版本锁定，模型只加载系统生成的可信产物。

验收重点：导入校验与版本保留、无时间泄漏、独立测试、OHLC约束、按周期筛选、无模型达标处理、任务取消与恢复、AI故障降级、预测可复现和多股票隔离。性能阈值通过真实样本测定，不预先承诺训练时间。
