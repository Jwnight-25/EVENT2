# 实现说明（v0.4）

日期：2026-10-06。需求原稿位于requirements目录，保持基线；本文件解释当前实现及差异。

## 结构

React/TypeScript通过/api/v1访问FastAPI；数据库采用SQLAlchemy，迁移由Alembic管理。API处理请求，独立工作进程串行领取持久化任务，每个重型任务在单独子进程运行。SQLite适合当前单用户体验，PostgreSQL配置和迁移可直接使用。没有Redis、交易账户或下单模块。

业务模块：market（导入、行情、快照）、research（因果特征、训练、校准、预测）、worker（排队与资源预算）、integrations（外部行情及AI接口协议）、backup（备份校验）。

- CSV/XLSX预检、中文列名、JSON字段映射、成交量单位、行级错误、冲突跳过/新增修订。
- 日/月K线，一分钟数据及5/30/60分钟聚合；午休隔离，缺少周期时说明。
- 完整日线快照及模型校验值；训练、参数试验、诊断、历史预测记录。
- ARMA/ARIMA、SARIMA和Ridge真实训练；LightGBM分位数、ARIMA＋GARCH、小型N-HiTS/PatchTST可选适配器。
- 参数搜索在两个滚动验证窗口比较；独立经验区间校准，隔离最终测试；先用验证固定最多三个候选再验收。
- 下一交易日OHLC、20/60交易日直接多步预测，各目标残差、ACF/PACF、适用统计检验和拟合历史频域分析。
- 任务查询、取消、预算、单工作进程锁、异常恢复；研究模式可重复优化，独立验收检查最终测试是否已被使用。
- 手动预测、预测K线、逐日边际区间、期末区间、模型分歧、参考价格剩余空间和后续实际行情叠加。
- 外部联网AI解释接口、来源归档与失败降级；未配置时不生成假新闻。
- 本机启动脚本、SQLite备份恢复校验、PostgreSQL备份接口、双数据库CI。
- 每次代码提交要求更新修改记录，提供本地钩子和CI检查。

## 初始实验方法与限制

实验目标是1/20/60个交易日；界面明确显示交易日跨度，不将20/60步宣称为精确自然月。精确自然月期限、全路径覆盖、期间极值和7个月模型尚未实现。

数据按50%拟合、20%滚动验证、15%校准、15%最终评估划分；长周期自动检查标签边界和样本量。v0.4参数搜索在每个验证窗口末尾取最多32个连续交易起点，校准及最终评估末尾取最多128点（可设32—512）。v0.3均匀抽样的历史结果保留原样，不能将其诊断解释为连续日频检验。点数、实际日期及重叠情况均报告；末尾截取的指标不代表整个窗口的平均表现。

计算时限覆盖整次实验的所选周期，范围10—21600秒。新界面设置每个模型、每个周期的试验上限（1—40）；旧API的max_trials仍表示每周期所有非基准模型共享试验次数，未传trials_per_family时适用。时限耗尽的未完成产物不会发布，实际试验与失败原因保留。延长时限不会自动增大网格。每月训练只是操作建议，没有定时强制训练。

Ridge可设置α上下限，标准网格按对数间隔取6值，扩展12值；ARIMA实际改变p、d、q及其最高阶数；SARIMA改变季节阶数，扩展加入20交易日周期。LightGBM调整叶子数、估计器数和学习率；GARCH调整p/q；可选深度模型调整输入长度和训练步数。按模型轮转探索，以两段验证MAE选择每类最佳参数，不能根据最终评估回头调参。没有遗传搜索或保证优化到优胜的无限循环。缺少依赖、拟合失败、预算耗尽均明确报告。

指标包括MAE、RMSE、相对基准RMSE、偏差、最大误差、MASE（日变化缩放）、方向命中、覆盖率、宽度、Pinball和区间评分。Ljung-Box及ARCH检验是样本外误差的探索性诊断，长周期重叠误差不要求白噪声；p>0.05不等于证明可靠。

增加相对naive的配对绝对误差优势检验：检验平均（基准绝对误差−模型绝对误差）是否大于0，使用单侧HAC正态近似及候选间Holm校正；同时展示均值差的双侧95%近似区间。要求日期对齐、连续交易起点、至少30点及20个不重叠窗口；不满足则不给出p值。HAC滞后至少h−1，包含常用自动滞后值，样本限制确保不截断h−1。时序非平稳、反复搜索和多重尝试仍限制解释；不重叠窗口也不代表统计独立样本。优势显著性与工程入选门槛分别报告，未宣称显著性就是盈利能力。

首版筛选规则是工程初值：验证及测试MAE至少改善2%、两验证窗口不比基准差超过10%、实际覆盖不低于名义覆盖减15个百分点、区间宽度不超过基准1.25倍。覆盖目标默认90%。这些不是金融有效性的证明；API允许调整部分参数，运行前配置被冻结。

模型在校准期之前拟合，验收后不使用测试数据重拟合。预测用新输入，统计模型更新状态但不更新参数；输入完整快照和产物校验值保留复现依据。若后续要全数据重拟合，应设计新的时序校准与部署验证。

界面默认研究模式，可改变预算与参数重复训练；重复使用的末段标注“研究评估”，其模型不会入选或替换已有合格模型。独立验收同一快照、周期只允许一次；研究已访问的评估段也不能再声称是新独立测试。不同数据版本可能仍有大量评估日期重叠，不能完全防止跨版本过拟合，需要新的未使用数据与未来前向评估。

预测流程为：选择1—3个模型及周期→保存数值预测→可选联网解释。默认仅展示入选模型；主动切换研究试算可使用未入选产物，并在结果冻结experimental标记及当时入选状态。历史结果不受后续模型入选状态变化影响。多模型可分别切换查看OHLC和区间。AI不再是数值预测之前的选项。

ARIMA类和深度模型对次日开盘和影线使用拟合历史的辅助规则；Ridge/LightGBM对受约束的OHLC目标直接学习。各字段区间不提供整根K线联合覆盖保证。

GARCH通过固定参数更新波动状态，缩放经验校准宽度。LightGBM训练各目标的5%、50%、95%分位数，排序后使用中位估计并进行经验误差校准；当前区间不是原始分位数上下沿。

内置XSHG日历覆盖1991—2025；2026及以后的数据必须先导入可靠的完整自然日日历。日历CSV需date、is_open两列，开市为1，休市为0。自定义日历作为本机显式覆盖，预测结果保存实际使用的日期。未来需补充交易所专属日历和版本来源。

当前接收明确口径的raw/qfq/hfq文件，但没有实现复权因子获取与历史点时重建。研究者需保证文件口径一致及历史可得性；系统不自动把最新前复权数据视为无泄漏。

参考买卖区间和阶段高点退出策略没有经过验证，目前标记不可用，只展示模型价格区间和空间。10%为观察信息，不是自动持有判断；最长7个月通过逐月复核，不外推当前模型。

数据库需求原稿中的部分指标、诊断、预测点和来源实体在首版合并为JSON字段，便于迭代；行情修订、快照、任务、实验、模型、AI解释保持独立实体。后续高数据量可以迁移为更细粒度表与分区。

## 联网AI预留协议

配置.env：AI_ANALYSIS_URL（HTTPS或本机HTTP），可选AI_API_KEY。用户选择联网分析时，系统会将股票标识、模型结果及最近历史输入发送给配置的服务；配置前应了解该服务的数据处理方式。默认不发送任何外部请求。

请求JSON含schema_version、stock、forecast、instructions。服务自行接入联网检索和AI，返回：

```json
{
  "text": "区分事实与推断的研究说明",
  "model": "服务使用的模型标识",
  "sources": [
    {"url": "https://example.com/report", "title": "来源标题", "published_at": "2026-10-01T10:00:00+08:00"}
  ]
}
```

正文或来源缺失则失败降级，模型数字不改动。发布时间未知允许null，检索时间单独记录。密钥保存在.env，不进Git或API响应。本项目未实现特定厂商的联网AI服务，用户可按协议接入。

## 数据库切换与备份

默认SQLite：data/research.db。启用PostgreSQL时复制.env.example为.env，设置本机密码和DATABASE_URL，运行docker compose up -d db，再执行迁移。不能仅修改连接串就认为SQLite旧数据已自动转移。

备份前停止服务；运行：

```sh
.venv/bin/python -m backend.app.manage backup --destination backups/backup-001
.venv/bin/python -m backend.app.manage verify-backup --destination backups/backup-001
```

SQLite备份包含database.sqlite和data目录中的uploads/snapshots/models，manifest记录校验值。恢复时先验证，停止服务，保留当前数据目录，再将数据库恢复到配置的SQLite路径，将备份data内容恢复到DATA_DIR。旧数据应保留，恢复后重新启动验证股票与历史记录。

PostgreSQL需要与服务器兼容的pg_dump，输出database.dump；恢复需pg_restore到空数据库，并恢复同一备份的数据文件。本机Docker未运行，PostgreSQL应用路径由GitHub CI检查；本机PostgreSQL备份未实际执行。

## 验证与下一步

自动测试使用隔离目录和标注的合成数据，只用于验证程序逻辑，不作为真实股票预测表现。真实数据不会随仓库提交，也没有默认演示行情。

本机已导入招商银行600036样例，来源和范围见example-data.md。旧实验只有32个抽样评估点，模型均未通过改善门槛。后续需要复权数据、更多独立前向观察、分钟数据及有证据支持的参考价格策略；不能承诺增加预算就必然出现可靠模型。

统计方法参考：[时序交叉验证](https://otexts.com/fpp3/tscv.html)、[残差诊断的用途与限制](https://otexts.com/fpp3/diagnostics.html)、[Statsmodels HAC协方差](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)。
