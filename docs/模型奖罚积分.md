# 模型奖罚积分（v0.12）

规则由用户于2026-10-13指定，2026-10-14落实。首批核对的是10月12日保存、预测10月13日的儒意电影OHLC；不随实施日期改变目标交易日。

## 计分规则

同一股票、同一个预测交易日，比较所有按时发布并取得同源真实行情的模型，包含naive基准。把预测和真实开盘、最高、最低、收盘分别按人民币0.01元四舍五入（ROUND_HALF_UP）转为整数分，再计算四项平均绝对误差MAE，误差越小越接近。

| 情形 | 积分 |
|---|---:|
| 四个价格全部与真实价格相同 | +5，不再叠加+2 |
| 四项平均误差最小，且未全对 | +2 |
| 四项平均误差最大 | −2 |
| 其他模型 | 0 |

并列最好/最差都获得对应积分。全部模型误差相同且非全对时全部0分；全部全对时各+5。只有一个有效模型时，全对+5，否则0。失败、过期行情、错过盘前窗口或没有真实行情的任务显示待评分/缺失，不作为最差模型扣分。收盘后才能计分，不依据盘中价格提前评分。

“四项全对”不是仅收盘价一致，也不是实际价格落在很宽的预测区间。原始浮点MAE、RMSE、Bias和区间覆盖继续保存；界面将用于积分的分精度MAE与原值MAE分开显示。

## 保存与后续使用

新增daily_point_rounds独立表，关联原批次和真实行情修订，保存计分策略版本、参与模型/预测/误差记录、分精度数值、排名、积分、理由和参与集合哈希。重复检查相同批次、真实修订与参与集合不会生成新一轮或重复加分。真实行情修订或有效参与集合变化时追加轮次，旧轮次可追溯；累计只采用每股每预测日的最新一轮，同一交易日只计一次。

预测页“模型积分榜”同时显示所选日积分、排名MAE、累计积分和已评分交易日。累计按同股票同模型类型跨模型版本汇总。JSON接口返回scoring_rule、leaderboard、points_through、每个task的score及批次points_awarded_at。

以前的daily_outcomes及相对基准的连续误差奖励不改写，保留为历史诊断；新界面的奖罚与后续搜索预算改用本积分规则。最近最多20个真实前瞻积分样本，至少5个且平均积分为负才将试验上限由4提高到6，Ridgeα搜索邻域有限扩大。Bias仍基于原始误差，至少5个真实样本才启动已有的有限校正。积分与误差都必须在训练配置冻结前已经入库，不能事后泄漏到旧预测。

盘前恢复运行时，先补齐行情并核对此前已收盘的预测，再冻结新训练配置。积分不是交易收益，不证明未来模型盈利；目前每类只有一个积分样本，不因单日结果立即放大参数搜索或修改已发布预测。

原始核对响应、请求地址、校验值及本轮回执位于统一运行数据audits/daily-points，随完整备份保存，不提交GitHub。
