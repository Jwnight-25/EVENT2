# 每日模型偏差统计

更新时间：2026-10-25。

预测分析页新增独立统计区，按股票、预测交易日及模型类型查看已发布OHLC预测与真实价格的偏差。默认列出“已可比较”，可切换“全部运行记录”查看准备中、未生成预测或等待行情的原因；缺失值显示为横线，不作为零偏差或零分。

## 数据与口径

仅接受同股不复权次日自动预测，须标记automatic_daily、目标日期一致、输入数据截止早于目标日，并在目标日北京时间09:15前发布，任务已ready。真实日线必须来自该股票固定MarketFeed的同一来源，且已到目标日15:30。未满足条件的记录不进入误差汇总。

使用发布时的candle（包含当时已冻结的偏差校正），不重新训练或回填过去预测；原始未校正预测仍可在旧模型详情中查看。对比真实值取bar_current指向的当前同源修订。查询为只读计算，不创建daily_outcomes或积分轮次、不触发重训；行情修订后统计反映新修订，已保存的历史奖惩保留其原评分版本，等待既有收盘评分流程独立处理。

每条结果返回batch_id、task_id、model_id、prediction_id、published_at和actual_revision_id，支持追溯。前端预测/真实价格与偏差显示4位小数，偏差率显示2位；计算和汇总使用未展示舍入的原值，与用于奖惩排名的人民币分精度口径分开。

## 指标

令四个目标为开盘、最高、最低、收盘，e为预测值减真实值。

| 指标 | 计算 |
|---|---|
| 各字段偏差 | e = published_prediction − actual；正数为高估、负数为低估 |
| 各字段偏差率 | e / actual，前端按百分数显示 |
| 四价Bias | 四个e的平均数，可因正负相抵而接近0 |
| 四价MAE | 四个绝对偏差的平均数 |
| 四价RMSE | 四个偏差平方的平均数再开方 |
| 四价MAPE | 四个绝对偏差率的平均数 |

按模型汇总只使用有效记录，每种模型每个交易日最多一条。字段平均偏差、Bias、MAE、MAPE按有效样本汇总；RMSE为所有有效交易日四价平方误差合并后的根均方，不能简单平均每日RMSE。有效交易日数作为样本数显示，不宣称样本相互独立或代表未来盈利能力。

## 筛选和接口

`GET /api/v1/daily-research/{stock_id}/deviations`

- start/end：可选ISO日期，包含两端；开始晚于结束返回422。
- family：可选模型类型，未指定时包括全部实际参加类型（含naive）。没有模型任务的漏跑批次单独显示，未安装类型不生成虚构记录。
- only_available：默认true，只影响明细列表；false返回全部运行记录。
- limit：1—200，默认50；offset为非负数。页面每页20条，按交易日倒序、模型类型与task_id稳定排序。

返回rows、total、offset、limit、families、checked_at和summary。summary按当前日期及模型筛选范围的全部有效记录计算，不受分页或only_available影响；status_counts及unavailable_count用于说明缺失。明细状态为available、preparing、no_forecast、awaiting_actual。

查询不受原daily_status最近20批次限制，按每股历史全量筛选，流式读取必要字段并累计，内存只保留当前页与模型汇总。页面每60秒刷新，也支持手动刷新；切换股票重置筛选、页码和详情，响应按股票/查询键隔离，避免显示前一个条件的结果。

本次复用daily_batches、daily_tasks、predictions、bar_current、bar_revisions、imports及market_feeds，不新增表或迁移，不修改已保存的预测、模型、误差或积分。
