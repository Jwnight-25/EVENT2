# 自动盘前预测、收盘反馈与信息情报（v0.11）

更新时间：2026-10-17。所有日程按北京时间Asia/Shanghai判断，与Mac的澳洲时区无关。v0.12奖罚按用户指定的积分规则更新，详见[模型奖罚积分](模型奖罚积分.md)。

## 每日流程

| 时段 | 自动工作 | 页面结果 |
|---|---|---|
| 上一交易日15:30收盘更新后，至目标日09:15前 | 确认上一交易日固定来源的完整不复权日线；冻结快照；分别训练已安装模型并预测下一交易日OHLC；夜间、周末及节假日可继续准备，盘前检查复用已有批次 | 预测页自动读取，无需点击生成 |
| 09:15截止 | 停止发布本交易日的新盘前预测，未完成任务说明原因 | 成功结果保留；迟到结果不能冒充盘前结果 |
| 交易日15:30以后 | 按原来源更新行情，将当天真实OHLC与事先保存的预测比较 | 保存Bias、MAE、RMSE、MAPE、区间覆盖、方向与奖罚 |
| 每日07:00—22:00 | 每2小时排队更新股票新闻、个股研报、行业研报 | 信息情报页滚动浏览，保留来源和时间 |

后台每5分钟检查一次，工作进程串行执行重型任务，盘前任务优先。已安装的macOS两个用户服务独立于网页和API。Mac必须开机、登录并保持唤醒；关机或休眠错过的盘前窗口不会补造，行情可在恢复后补齐。交易日历未知时停止行情和预测，但情报更新仍可继续。

2026-10-17起正常调度自动提前准备下一交易日，不再依赖仅07:00—09:15的窄窗口或首次手动准备。`--prepare-next`保留兼容；同股同日不重复训练或预测，已冻结批次不因早晨检查而改写。尚未取得固定来源上一收盘日数据的批次，在截止前继续等待并重试；09:15以后仍禁止补算已开盘日。

## 模型范围和预算

自动流程覆盖每一种依赖已安装的模型类型，每类每天保存一个成功的最佳参数版本，包括naive比较基准。未安装的LightGBM、ARIMA＋GARCH、N-HiTS、PatchTST明确列为未参加，不以模拟结果代替；以后安装相应依赖即可参与下一批次。失败、未收敛和超时按模型记录，允许部分成功。

每类训练最多300秒，通常最多4次参数试验；反馈较差时最多6次。单模型最新拟合与预测最多180秒，另外受09:15截止约束。不同股票串行排队，扩展到大量股票或深度模型后需要重新评估时间与内存预算。默认单线程重型计算适合当前M3/16GB环境。

2026-10-14起默认每次训练同时优化结构数量及参数大小：Ridge搜索特征数和α，ARIMA/SARIMA等细化阶数与各自设置。4次预算也为细化预留一次，原奖罚门槛与时间预算不变；详见[参数数量与大小优化](参数数量与大小优化.md)。

自动版本标为“盘前自动候选”，用于积累真实前瞻成绩；不将其标为已正式验收。原手动训练保留最后15%三折时序交叉验证及95%价格匹配门槛，已有手动入选模型不被每日候选撤销。自动页展示历史匹配供参考，匹配度不是未来方向命中率或盈利概率。20/60交易日预测和AI解释仍按需操作。

次日OHLC沿用现有模型实现：Ridge等学习受约束目标，ARIMA等的开盘和影线使用历史辅助规则；各字段区间是边际区间，不保证整根K线联合覆盖。可以展开模型查看原始数值、校正值、各目标区间及收盘误差，也可打开完整图表并点击生成AI解释。AI仍需真实供应商配置。

## 收盘评分和奖罚

预测、数据快照、参数和发布时间一旦发布即冻结。收盘核对必须使用该股票固定来源对应的真实行情修订，不使用别股或其他来源。重复检查不重复评分；若以后确认行情修订，则追加评分版本，旧预测与旧评分不改写。

- 带符号误差：`预测−实际`，正值代表高估。
- Bias：当天开、高、低、收四个带符号误差的均值；每个字段的误差另存。
- MAE/RMSE/MAPE：当天四个价格目标的平均绝对误差、均方根误差、平均绝对百分比误差。
- 方向：预测收盘相对前收的方向与真实方向是否相同。
- 区间覆盖和区间评分：分别保存各字段及总体结果；单日只有4个目标，不能当作长期覆盖证据。
- v0.12积分：四价统一按分四舍五入后比较MAE；四价全对+5、最接近+2、最差−2，其余0，并列同分；全部同误差且非全对则0。没有有效预测的任务不扣分。历史相对基准连续奖励仍保留为旧诊断，不再驱动新搜索预算。

下一批训练只读取此前已收盘、且在该批配置冻结时已经入库的评分。行情修订的多个评分版本只计一个预测样本；最多取最近20个预测交易日。至少5个真实样本之后，分别对四个字段计算原始预测的平均偏差，校正量为其相反数的25%，并限制在前收参考价的±0.5%。校正后重新约束OHLC关系，区间随对应目标平移；原始预测始终可查。这是保守的反馈规则，尚不保证改善精度。

优先把上次同类型最佳参数放入搜索候选。最近积分均值为负且积分样本至少5个时，试验上限由4提高到6；Ridge的α邻域扩大为旧最佳值的1/100—100倍，否则在样本足够时为1/10—10倍，始终限制在0.01—100000。其他模型沿用各自有界候选网格。搜索次数和连续参数大小均可变化，但不能无限优化，也不能根据未来真实结果调整已发布预测。

这是一套可审计的误差反馈和自适应调参机制，尚未实现交易强化学习代理。要判断是否有效，需要累积真实盘前样本，分别比较原始与校正后的误差、基准优势与区间评分。

## 信息情报

固定使用东方财富公开股票新闻检索和研报目录。新闻按六位代码检索；行业代码来自个股研报元数据，并核对返回行业，不能识别时明确跳过行业项。个股和行业研报查询最近180个自然日，每源每次最多30条；新闻每次最多30条。系统不能保证供应商历史目录完整。

只归档标题、原文链接、机构、发布时间、检索时间和短摘录；不自动生成AI摘要，不下载报告全文。新闻标为关键词关联，广泛行情列表可能只包含股票代码，不自动认定直接影响股价。研报仅显示供应商提供的发布日期时不编造具体时分秒。

原响应、请求地址、抓取时间和哈希存入`audits/intelligence/`，同股票同类型原文链接去重；不同来源的转载可能分别展示。网络失败保留历史内容，展示失败记录；新股票行业未知不假定匹配。每页30条、游标分页，切换股票或分类回到最新内容，页面每60秒读取后台更新。

## 安装和维护

先安装依赖并迁移数据库，再运行：

```sh
python -m backend.app.manage migrate
python scripts/install-market-updater.py \
  --project '/Users/xyjin/Desktop/项目组/项目1' \
  --python '/path/to/venv/bin/python' \
  --data-dir '/Users/xyjin/Desktop/项目组/项目1/运行数据' \
  --backup-dir '/Users/xyjin/Desktop/项目组/项目1/完整备份'
```

安装器创建或更新当前用户的`com.event2.market-update`与`com.event2.worker`两个LaunchAgent。前者执行`manage market-cycle`，后者保持任务工作进程运行；重装前须等待任务空闲，避免打断正在发布的结果。Python环境、桌面代码与数据目录都必须持续存在。移动项目或删除虚拟环境后需要重新安装服务。

其他系统可每5分钟运行`python -m backend.app.manage market-cycle`，同时保持`python -m backend.app.worker`运行。`update-market`仍只执行行情子流程，供手动维护。日志位于统一运行数据的`logs/market-updater*`和`logs/worker-background*`。

新增数据库表：daily_batches、daily_tasks、daily_outcomes、intelligence_items、intelligence_syncs。完整备份包含这些记录、预测与模型产物及情报审计材料。实际数据、密钥、日志和本机服务配置不进入GitHub。

## 漏跑记录与恢复（2026-10-17）

恢复运行时，从该股票最早已有自动批次起，按交易日历检查已过09:15的交易日，补记缺少批次的日期为missed。没有监测历史的新股票不追溯其全部行情；周末和节假日不生成漏跑记录。这些记录标明实际发现时间、原因代码和缺少预测，不创建模型、预测、误差或积分。行情补齐后，只有原先按时发布的有效预测才可评分。

等待数据超时保留具体缺失日期，训练或预测超时保留截止原因；迟到的任务回调不得将missed改写为普通失败。预测页列出最近8个已有或漏跑批次的同源行情、有效模型数、评分状态及错误，点击交易日查看详细OHLC。缺少预测显示“无法评分”，不等同于0分；累计积分仍仅取有效真实评分。返回最近20个批次。

`coverage`包含prediction_count、scored_count、actual_available、actual与settlement。真实行情仅在15:30后且原导入来源与固定feed一致时展示；settlement区分preparing、awaiting_actual、settlement_pending、scored和no_forecast。实际价格或预测尚未齐全时不捏造结果。

提前准备扩大了本机可执行时段，但电脑休眠、关机或未登录时仍无法保证后台工作。此更新不修改Mac的睡眠设置，也不声称能在关机时运行。
