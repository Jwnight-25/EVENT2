# 每次训练的参数数量与大小优化

更新：2026-10-14。默认覆盖手动训练与每日盘前训练，无需逐个手工调整参数。优化受每类试验数、整次计算预算、明确参数边界及盘前截止共同约束，不能保证得到更准确的模型。

## 数量和大小分别指什么

| 模型 | 数量/结构 | 数值大小 |
|---|---|---|
| Ridge | 收益率滞后特征数量，默认3—10个；另保留11个因果行情特征 | α正则化强度；每次拟合重新学习系数 |
| ARMA/ARIMA | p、d、q阶数及对应实际拟合参数数目 | 各候选重新估计统计系数与方差 |
| SARIMA | 非季节阶数、季节AR/MA项，季节周期5/20交易日 | 各候选重新估计统计系数与方差 |
| LightGBM（依赖未安装） | 树数、叶数 | 学习率 |
| ARIMA＋GARCH（依赖未安装） | 均值模型阶数、波动p/q | 拟合均值/波动参数 |
| N-HiTS/PatchTST（依赖未安装） | 16/32/64宽度、1—3层及输入窗口 | 学习率、训练步数 |

naive是固定比较规则，没有可调自由参数。可选模型仍需安装依赖并实际训练成功，当前没有将它们的接口适配或测试替身声称为真实训练结果。

Ridge的基础特征矩阵保持原有21列与列顺序，避免改变旧模型解释。新模型只选指定的收益率滞后列和另外11列，模型产物保存选列索引；预测、交叉验证和最新拟合使用同一组选列。原模型缺少选列信息时仍按原21列预测。

次日Ridge有四个学习目标，参数数量为`4×输入特征数＋4个截距`：默认3个滞后对应14个输入、60个参数；6个滞后对应17个输入、72个参数；10个滞后对应21个输入、88个参数。20/60日模型的目标数量不同，参数数目也不同。参数数量不等于试验次数。

页面同时显示Ridge标准化系数绝对均值和最大值；这些来自实际拟合产物。统计模型显示实际估计的均值模型参数数量（含方差；不包含OHLC辅助形态统计量），GARCH时加上波动参数；树模型按树数与叶输出数量单列，网络按实际可训练权重数统计。这些定义不同，不能用数量直接跨模型排名或推断精度。

## 每次训练如何选择

1. 默认把此前同股票、同口径、同周期、数据截止兼容的最新模型参数作为一个候选，冻结原模型ID及参数，保留新范围内可用的设置。超出当前边界的候选跳过，不越过用户限制；旧参数不保证再次胜出。
2. 分阶段模式先粗搜，保留约一半试验预算用于细化；预算足够时至少比较三个粗搜设置。每类4次时可完成3次粗搜和1次细化，6次时通常为3＋3，12次时通常为6＋6。参数集合较小、重复候选及早停可减少实际次数。
3. 细化读取两个调参区段的误差，围绕当时最优候选提出未试过的参数：Ridge细化α及相邻特征数量，ARIMA/SARIMA调整相邻阶数/季节项，其他类型调整各自的有界设置。失败候选保留原因；无可细化候选时可尝试剩余网格。
4. 细化连续3次没有0.1%改善、没有新候选、试验次数达到上限或预算用尽即停止。最终交叉验证、收盘真实答案不用于这一轮反复换参数。预算只有1次时无法比较多个候选。
5. 每类保存调参最优且通过对应拟合流程的版本，不要求参数数量一定增大或减小。原实验、权重和预测保持冻结，新训练另存版本。

原标准/扩展网格模式继续可选，默认分阶段模式现在覆盖所有非基准类型。手动训练可调整Ridge特征上下限、α上下限、ARIMA最高阶数、试验数与总预算，也可关闭Ridge/网络结构搜索或关闭以前版本候选。

每日盘前仍每类300秒、通常4次，满足已有负积分样本条件时6次，09:15截止；新联合搜索也使用这一预算。已有积分规则及Bias反馈没有降低样本门槛。

## 审计与首次实际运行

每个optimization_trials报告保存粗搜/细化/补充探索阶段、实际设置、调参误差、成功/失败及拟合规模。models.metrics.structure保存最终产物的规模与系数幅度；预测独立最新拟合的deployment.structure另行记录。历史JSON缺少这些字段时不补造。

2026-10-14使用儒意电影真实不复权日线完成研究实验`67ae1e91-8573-4eef-ad87-f05834fcaf39`，耗时38.9秒。Ridge7次、ARIMA7次、SARIMA8次，另有naive基准。Ridge实际尝试60/72/84/88个参数，α包括0.01、31.6228、31622.7766、56234.1325、100000；ARIMA成功候选2/3/4个参数，SARIMA3/4/5个。

最终Ridge选择α=100000、10个滞后、88个参数；ARIMA选择(0,1,1)、2个参数；SARIMA选择(0,1,0)与(1,0,1,20)、3个参数。两次ARIMA调参未收敛，保留失败，没有强行修改结果。该次研究实验不替代已入选模型，也没有用它改写以前预测或声称未来精度已经提高。
