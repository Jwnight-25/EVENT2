# 招商银行样例数据

2026-10-06经用户确认，已将招商银行（上海证券交易所，600036）的公开日线导入本机系统数据库。

## 数据与处理

- 来源：东方财富公开历史K线，下载于2026-10-06 10:49 UTC。
- 数据范围：2016-01-04—2026-09-30，共2,611条日线。
- 文件格式：UTF-8带BOM的CSV，列为`date,open,high,low,close,volume,amount`。
- 日期格式：`YYYY-MM-DD`，按交易日期递增；市场时区为Asia/Shanghai。
- 价格口径：不复权；开高低收与成交额为人民币元；原接口成交量由手乘100转换为股。导入时明确选择“股”，不重复转换。
- 交易日历：覆盖2016-01-01—2026-12-31的4,018个自然日。2016—2025年采用exchange_calendars XSHG 4.11.1，2026年按上交所正式休市公告及周末休市规则整理。
- 数据库：当前为SQLite，使用现有版本化行情表；当前记录以股票、周期、价格口径、交易日期为联合键，并保留导入批次、来源校验值及不可变快照。
