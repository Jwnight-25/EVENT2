# 每日收盘数据更新

每只股票沿用自己的原始行情来源：招商银行600036使用东方财富，儒意电影002739使用腾讯。都是不复权日线；不会因为另一家接口可用就切换供应商。新股票需先有带可核验来源的基础导入，未知来源不会自动启用。

## 执行时间与断线恢复

- 按北京时间（Asia/Shanghai）判断交易日，默认15:30开始检查，留出收盘后的数据发布时间。澳洲夏令时变化不影响判断。
- Mac当前用户登录后，后台每5分钟检查是否到期；同一收盘日成功后不再重复抓取。关闭网页和API不影响已安装的独立更新服务。
- Mac休眠、关机、未登录或离线期间不能更新；恢复运行后按已有数据截止补齐可获取的完整日线，而不是只请求恢复当天。
- 连接失败、接口延迟或缺少当日行情时，保留旧数据。每15分钟重试，同股票、同目标收盘日在一个北京时间自然日内最多6次自动尝试；次日重置该尝试预算，支持盘前继续补齐上一日。可在“数据与备份”主动重试未完成的检查。
- 周末和节假日不生成行情。跨年时需补充已确认的交易日历；未知日历会停止本次更新并报告原因。

## 数据保护

后台更新与备份、训练/预测计算、手工写入互斥，忙时留待下个检查周期。两个更新进程不能同时更新同一数据库。

每次取最近截止前7个自然日作为重合检查窗口，按年请求以避免接口条数截断。固定股票标识、不复权参数、字段顺序和单位，拒绝未收盘或无效日期、非法价格和重复来源日期。成交量统一为股，腾讯当前接口没有成交额时保存NULL，不估算。

只追加新日期；重合日期的OHLC、成交量或成交额与当前记录不一致时，暂停该批次写入，保存差异供人工核查。原始响应、请求时间/地址、SHA-256、标准CSV、导入批次及结果都保留。进程中断后重新检查，已写日期不会重复发布。缺少行情可能涉及停牌或供应商遗漏，不插值、不制造K线。

行情更新子流程负责数据。v0.11的统一调度另行执行盘前训练、自动预测、收盘评分和情报更新，详见[自动盘前预测与情报](自动盘前预测与情报.md)。已有实验、模型、快照和预测数字保持冻结。行情页仅展示日K；后端旧月线和分钟聚合接口保留，分钟及复权不在自动更新范围。AI解释仍需主动点击。

## 查看状态

网页左侧打开“数据与备份”，可查看当前股票的固定来源、最近完成收盘日、最早下次检查时间、最近执行结果及差异。点击“检查并补齐收盘数据”可重试未完成检查；已经成功的收盘日不重复请求。页面每60秒核对数据截止，只有数据变化才刷新行情。

错误记录中的failed表示本次请求失败；waiting表示未取得目标日行情；两者都不代表已补齐。完整备份包含数据库中的来源/运行记录以及audits下的原响应和结果。已有历史记录的保存情况可用导入前完整备份复核。

## 安装和维护

安装器只创建当前用户的macOS LaunchAgent，不需要管理员权限。必须先迁移数据库，使用已安装项目依赖的Python环境。示例：

```sh
/path/to/venv/bin/python -m backend.app.manage migrate
/path/to/venv/bin/python scripts/install-market-updater.py \
  --project '/Users/xyjin/Desktop/项目组/项目1' \
  --python '/path/to/venv/bin/python' \
  --data-dir '/Users/xyjin/Desktop/项目组/项目1/运行数据' \
  --backup-dir '/Users/xyjin/Desktop/项目组/项目1/完整备份'
```

安装器会检查项目与Python依赖，并验证服务已经加载。Python路径保留虚拟环境入口，不解析到缺少依赖的全局解释器。`--dry-run`只输出配置，不安装。

后台配置：`~/Library/LaunchAgents/com.event2.market-update.plist`和`com.event2.worker.plist`。统一检查日志为`运行数据/logs/market-updater.log`及`market-updater-error.log`，工作进程日志为`worker-background.log`及`worker-background-error.log`。系统迁移到其他电脑、Python环境删除或项目路径移动后，需重新运行安装器；重装前等待任务空闲。

其他系统可由自己的调度器每5分钟执行：

```sh
python -m backend.app.manage market-cycle
```

同时保持`python -m backend.app.worker`运行。只维护行情时仍可手动执行`python -m backend.app.manage update-market --stock-id ID --retry`，立即重试指定股票的未完成检查。运行记录与原始材料保存在数据库及`运行数据/audits/market-updates/`。本机数据、操作系统服务配置和密钥不推送GitHub，代码和使用说明通过Git同步。

免费公开接口可能临时不可用；系统记录真实失败并按同一来源重试，不承诺每次15:30都能立即取得数据。
